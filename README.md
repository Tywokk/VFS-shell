# VFS Shell Emulator

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом
(Python 3, tkinter). Практическая работа, вариант 28.

## Общее описание

Окно с областью вывода и строкой ввода. Ввод делится по пробелам на
команду и аргументы. Заголовок окна содержит имя VFS. При запуске в окно
и в stdout выводятся все заданные параметры (`[debug] ...`).

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--log PATH` | путь к XML-логу вызовов команд (без параметра лог не пишется) |
| `--script PATH` | стартовый скрипт эмулятора |

На этапе 2 `--vfs` только принимается и выводится в отладочном режиме.

## Команды

| Команда | Описание |
|---------|----------|
| `ls [args]` | заглушка: печатает имя и аргументы |
| `cd [args]` | заглушка: печатает имя и аргументы |
| `exit` | закрывает эмулятор |

Ошибки (неизвестная команда, аргументы у `exit`) выводятся красным.

## Лог (XML)

Файл обновляется после каждой команды:

```xml
<events>
  <event>
    <time>2026-10-05T12:00:00</time>
    <command>cd</command>
    <arguments><arg>/tmp</arg></arguments>
  </event>
  <event>
    <time>2026-10-05T12:00:01</time>
    <command>foo</command>
    <arguments><arg>bar</arg></arguments>
    <error>foo: команда не найдена</error>
  </event>
</events>
```

## Стартовый скрипт

Одна команда на строку; пустые строки и строки с `#` пропускаются.
В окне отображаются и ввод, и вывод, как в диалоге. Выполнение
останавливается на первой ошибке с сообщением
`Скрипт остановлен: ошибка в строке N`. Примеры: `scripts/*.emu`.

## Скрипты ОС для проверки параметров

Каждый скрипт в `scripts/` запускает эмулятор с параметрами `--vfs`,
`--log` и `--script` и проверяет результат (общие функции в `lib.sh`):

| Скрипт | Что проверяет |
|--------|---------------|
| `test_params_basic.sh` | каждый параметр отдельно и все три вместе |
| `test_params_log.sh` | содержимое XML-лога, остановка скрипта на ошибке |
| `test_params_errors.sh` | неизвестные параметры, параметры без значения |

Скрипты написаны для sh (Linux, macOS; в Windows через Git Bash или WSL).

## Сборка и тесты

```
make run ARGS="--log log.xml --script scripts/startup_ok.emu"
make test      # unit-тесты
make test-os   # скрипт ОС: проверка параметров командной строки
make lint      # flake8, длина строки 80
```

Требуется Python 3.9+ с tkinter (Debian: `apt install python3-tk`).
Без дисплея: `RUNNER="xvfb-run -a" make test-os`.

## Примеры

```
user@vfs:~$ ls -l /home
ls: заглушка, аргументы: -l /home
user@vfs:~$ foo
foo: команда не найдена
user@vfs:~$ exit 1
exit: слишком много аргументов
user@vfs:~$ exit
```
