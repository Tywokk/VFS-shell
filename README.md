# VFS Shell Emulator

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом
(Python 3, tkinter). Практическая работа, вариант 28.

## Общее описание

Окно с областью вывода и строкой ввода. Ввод делится по пробелам на
команду и аргументы. Заголовок окна содержит имя VFS.

## Команды (этап 1)

| Команда | Описание |
|---------|----------|
| `ls [args]` | заглушка: печатает имя и аргументы |
| `cd [args]` | заглушка: печатает имя и аргументы |
| `exit` | закрывает эмулятор |

Ошибки (неизвестная команда, аргументы у `exit`) выводятся красным.

## Сборка и тесты

Требуется Python 3.8+ с tkinter. Сборка не нужна, достаточно запуска.

**Установка tkinter**
- Windows: tkinter входит в установщик Python с python.org, ничего
  ставить не нужно.
- Debian/Ubuntu: `sudo apt install python3-tk`

**Linux/macOS** (из корня проекта):

```
make run    # запуск GUI
make test   # unit-тесты
make lint   # flake8, длина строки 80
```

**Windows** (из корня проекта, в cmd или PowerShell):

```
python -m src.main
python -m unittest discover -s tests -t .
```

Эти же две команды работают на любой системе, `make` их только
сокращает.

## Примеры

```
user@vfs:~$ ls -l /home
ls: заглушка, аргументы: -l /home
user@vfs:~$ cd docs
cd: заглушка, аргументы: docs
user@vfs:~$ foo
foo: команда не найдена
user@vfs:~$ exit 1
exit: слишком много аргументов
user@vfs:~$ exit
```
